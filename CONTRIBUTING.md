# Contributing

Thanks for helping improve Roommate Compatibility Predictor.

## Before making a change

1. Open an issue describing the bug or improvement, if appropriate.
2. Keep changes focused and explain why they are needed.
3. Never include real student names, emails, room numbers, or identifiable survey responses.
4. Do not commit credentials, `.env` files, virtual environments, caches, or local datasets.

## Development workflow

1. Create a branch from `main`.
2. Create and activate a Python virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run the application locally and follow `docs/TESTING_CHECKLIST.md`.
5. Describe manual tests performed in your pull request.

## Pull request checklist

- [ ] The change has a clear purpose and description.
- [ ] Existing profile selection and manual profile entry were checked if affected.
- [ ] Missing or malformed input is handled clearly.
- [ ] No private or identifiable student data is included.
- [ ] Documentation is updated where needed.
